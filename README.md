# 사각사각 몬스터 앱 프로젝트 (안드로이드 시험 빌드)

웹 게임을 안드로이드 앱으로 감싸는 프로젝트예요. 게임 코드는 웹 버전과 같은 파일(`www/` 폴더)을 그대로 담았어요.
이 폴더를 GitHub에 올리면 GitHub가 대신 앱 파일(APK)을 만들어 줘요. 내 컴퓨터에 설치할 것은 없어요.

## 시험 앱 받는 방법

1. GitHub에서 **새 저장소**를 만들어요 (이름 예: `sagsag-monster-app`).
   기존 웹 게임 저장소(Monster-Cutting_game)는 건드리지 마세요. 새 저장소를 따로 만들어요.
2. 새 저장소에서 **Add file > Upload files**를 눌러요. 이 폴더 안의 **모든 파일과 폴더**를 끌어다 놓아요.
   `.github` 폴더도 꼭 같이 올려야 해요 (앱 만드는 설명서가 이 안에 있어요).
   `Commit changes`를 눌러 저장해요.
3. 저장소 위쪽 **Actions** 탭으로 가요. "안드로이드 시험 빌드"가 자동으로 실행되고 있을 거예요. (안 되어 있으면 왼쪽에서 이름을 눌러 **Run workflow**)
4. 초록 체크가 뜨면(보통 몇 분) 그 실행을 눌러 맨 아래 **Artifacts**에서 `sagsag-monster-debug-apk`를 내려받아요. 압축을 풀면 `app-debug.apk`가 나와요.
5. 안드로이드 폰으로 옮겨서 설치해요. 폰에서 "이 출처의 앱 설치 허용"을 물어보면 허용해요.

빨간 X가 뜨면 그 실행 화면(로그)을 캡처해서 알려 주세요. 제가 원인을 찾아 고쳐 드릴게요.

## 폰에서 확인할 것

- 앱이 열리고 세로 화면으로 고정되는지
- 소리가 나는지 (효과음, 보스 음악)
- 블록을 밀고 터치하는 게 웹과 똑같은지
- 화면 위아래가 잘리지 않는지 (상단 카메라 부분, 아래 버튼 영역)
- 광고 보기, 도전장 보내기(공유) 버튼이 동작하는지 ← 앱 안에서는 다르게 동작할 수 있어요

## 알아 둘 점

- 이 앱은 **시험용**이에요. 스토어에 올릴 앱은 나중 단계에서 따로 만들어요.
- 앱 고유 번호(패키지 이름)는 임시로 `com.cuttingmonsterblock.game`으로 정했어요. 스토어에 올리기 전까지는 바꿀 수 있고, **올린 뒤에는 바꿀 수 없어요.**
- 아이콘은 아직 기본 아이콘이에요.
